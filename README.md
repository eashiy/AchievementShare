# AchievementShare
This is an ESO add-on I am working on with the intent to be able to easily see group achievement progress in an ingame UI without people sharing things via chat. 
My current plan is to start with the Dungeon Achievements and see how it goes. After that I will add things like trials, night market relics, and other achievements. Aneversary achievements relating to the style pages will also be added down the line to make it easier for groups to help people farm these. 
An additional feature will be added in the future which allows dungeon and or trial achievements to be exported thenn converted to a spread sheet for offline tracking.
